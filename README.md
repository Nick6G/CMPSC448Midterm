This is a repository for Nick Gauthier's CMPSC 448 Midterm Project. The data for this project comes from https://data.mendeley.com/datasets/prcjcggtjf/1 the original dataset was too large to add to this repository. This repository includes the python files used to wrangle the original data, create datasets for output only, input only, and input and output, and to create the CNN and LSTM models. This repository also includes the csv files training, validation, and testing, made from the data wrangling code from the orignal csv file. It also contains the .pt file for the best model for both the CNN and LSTM for the output only, input only, and both input and output runs. It also contains the PDF MidtermProject which is the final report for this project.
